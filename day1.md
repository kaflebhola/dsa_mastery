## Day 1 — Complexity Analysis

### What is Complexity Analysis?

Complexity Analysis is a technique used to characterize the time and space resources required by an algorithm with respect to its input size.

It evaluates how an algorithm's resource requirements change as the input size increases, independent of:
- Machine
- Programming language
- Compiler

Complexity analysis is mainly used to evaluate and compare different algorithms based on their efficiency.

### Why Do We Need Complexity Analysis?

Complexity Analysis helps us:
- Determine the time required to execute an algorithm.
- Determine the space (memory) required by an algorithm.
- Compare the efficiency of different algorithms.
- Understand how an algorithm behaves with different input sizes.
- Determine the difficulty and scalability of solving a problem.

### Key Idea

Complexity is often measured by how much time and space an algorithm requires as the input size grows.

### Summary

| Concept | Meaning |
|---|---|
| Time Complexity | Measures how the execution time grows with input size. |
| Space Complexity | Measures how the memory usage grows with input size. |
| Purpose | Compare algorithms and determine their efficiency. |
| Focus | How resource requirements change as input size increases. |
